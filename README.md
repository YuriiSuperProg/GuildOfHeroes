## Собственный проект

Тема проекта: Автопарк

Главный класс: Car

Почему этот объект нужен программе:
Car описывает одну конкретную машину в автопарке. Программа должна
хранить данные о нескольких машинах одновременно, а класс позволяет
держать все характеристики одной машины вместе и создавать сколько
угодно независимых объектов с собственным состоянием.

Какие данные хранит объект:

- Brand — марка машины (string)
- Model — модель (string)
- EngineVolume — объём двигателя в литрах (double)
- Year — год выпуска (int)
- Color — цвет (string)
- IsAvailable — доступна ли машина (bool)

Какие значения задаются через конструктор:
Brand, Model, Year, Color, EngineVolume — эти данные уникальны
для каждой машины и не могут быть придуманы программой, поэтому
передаются при создании объекта.

Какие значения можно задавать автоматически:
IsAvailable = true — новая машина при добавлении в автопарк
по умолчанию доступна для использования, поэтому это значение
назначается внутри конструктора без параметра.

### Дополнительное задание

Автоматически задаваемое значение: IsAvailable = true.

Почему: машина, только что добавленная в автопарк, по умолчанию
свободна. Передавать true при каждом создании объекта избыточно,
поэтому значение устанавливается внутри конструктора. Если машину
забронируют, поле можно изменить позже: `bmw.IsAvailable = false;`

Проверка: при создании объектов bmw, lada и tesla поле IsAvailable
равно true — это видно в выводе программы.
